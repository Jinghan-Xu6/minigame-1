# Minigame 1
## Devlog
Metaphor：A Scene is a video game room. Each GameObject is an object inside this room. Components are what give each object its powers. One component makes the player walk, another makes coins collectable, and spikes hurt you when touched. 

For my work, I made a new platform level. I put 8 coins and 6 spike hazards. I changed the player’s move speed to 6.
